# WU-03 — AI SDK structured-output spike: plan

**Status:** approved (2026-10-27) · **Depends on:** WU-01 (done) · **Author:** main agent (Opus), 2026-10-27

## 1. Goal & scope

**Goal** (from `docs/work-breakdown.md`): remove the biggest technical unknown before building on it. The code is throwaway; the decision record is permanent.

**Questions to answer** (CLAUDE.md §8.2)
1. Which API in the pinned `ai` + `@ai-sdk/anthropic` produces structured output: `generateObject`/`streamObject`, or `generateText`/`streamText` with `output`?
2. Does it work on `claude-sonnet-5-5` and `claude-haiku-5-5` without a forced `tool_choice`, i.e. through native structured output?
3. Does a required-but-nullable schema (§4.4) come back correctly? Are any Zod constructs rejected?
4. How is `effort` passed through provider options? Confirm that no sampling params are sent by default.
5. What do a `refusal` and a schema-invalid response look like to our code?
6. Can the provider take a custom `fetch`? WU-08's record/replay needs this.
7. Does the partial-object stream work with `useObject` when it reads a plain `text/plain` response?

**In scope**
- A standalone spike in `spikes/structured-output/`, marked non-production and kept out of `verify`, lint, typecheck and the pnpm workspace.
- A handful of live calls, costing a few cents.
- `docs/decisions/0001-structured-output.md`, which answers all seven questions and lists the exact versions tested.
- Any CLAUDE.md §4.4, §7 or §8 edits that the findings require, in the same commit as the ADR.

**Out of scope:** the real `LlmClient` and cassettes (WU-08), wire schemas and `zod` in the workspace catalog (WU-04), any `backends/` or `apps/` code, and the quality gates (WU-02, which isn't merged yet, so this unit's gate is `typecheck` + `lint` + `format:check` as in CI today).

## 6. Risks & open questions

## 8. Deviations during implementation

Recorded at review (2026-11-02). The plan body above is what was approved.

1. **Live calls: 15, not ~10 (D9).** The constructs matrix used one Haiku call per construct rather than one batched schema. That was about 9k tokens in total, a few cents.
2. **Streaming helper (D8).** `toTextStreamResponse()` is deprecated in `ai` v7; the probe used `toTextStream` + `createTextStreamResponse`, and CLAUDE.md §7/§8.2 now say so.
3. **Captures scrubbed after recording (D10).** Live response headers contained `anthropic-organization-id` and `anthropic-workspace-id`. The 15 live captures were rewritten to allowlisted headers (`content-type`, `request-id`), and `capture-fetch.ts` now allowlists response headers.
4. **Capture bug fixed and the stream re-run.** The first `captureFetch` awaited the stream body before returning, which delivered the SDK stream as one chunk. Fixed, and the one live stream call was re-run. Both pitfalls are recorded in ADR 0001 (Q6) for WU-08.
5. **Wider ADR consequences and work-breakdown notes.** The ADR's Consequences covers WU-04/05/06/08/09/10/11/12/14, not only the five listed in §3. Each affected unit got a Notes entry in `docs/work-breakdown.md`, and WU-08's Definition of done now also checks for account identifiers in cassettes. Approved by the user at review.
6. **Extra CLAUDE.md edit.** §2 layout gains `docs/decisions/` and `spikes/`.
7. **Open item handed on:** whether flexible `month` 1–12 joins `DATE_VALID` or gets a new rule code goes to WU-04/05 (R4); §4.6 was not edited.
